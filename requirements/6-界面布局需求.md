# 界面布局需求

## 1. 需求概述

本文档描述应用的整体界面布局,包括窗口设计、区域划分、响应式布局等,确保用户界面简洁直观、易于使用。

## 2. 整体窗口设计

### 2.1 窗口属性
- **标题**:"九宫格切图工具" 或 "Unity UI 九宫格切图助手"
- **图标**:应用图标(可选,使用默认图标或自定义图标)
- **初始尺寸**:
  - 宽度:1200像素(建议)
  - 高度:800像素(建议)
- **最小尺寸**:
  - 宽度:800像素
  - 高度:600像素
- **可调整大小**:是,用户可以拖动窗口边缘调整大小
- **最大化/最小化**:支持

### 2.2 窗口启动位置
- **默认位置**:屏幕居中
- **记忆功能**:记住用户上次关闭时的窗口位置和大小(可选)

## 3. 界面区域划分

### 3.1 整体布局结构
```
┌─────────────────────────────────────────┐
│           菜单栏 (Menu Bar)             │
├──────────────────┬──────────────────────┤
│                  │                      │
│   左侧操作区     │    右侧预览区        │
│  (Left Panel)    │   (Right Panel)      │
│                  │                      │
│                  │                      │
├──────────────────┴──────────────────────┤
│         底部导出按钮区 (Bottom Bar)      │
└─────────────────────────────────────────┘
```

### 3.2 区域尺寸比例
- **菜单栏**:高度约30-40像素
- **左侧操作区**:宽度占窗口的50%-60%
- **右侧预览区**:宽度占窗口的40%-50%
- **底部导出按钮区**:高度约60-80像素

### 3.3 区域分隔
- 左右区域之间使用**可拖动的分隔条**
  - 用户可以拖动分隔条调整左右区域的宽度比例
  - 分隔条宽度:3-5像素
  - 鼠标悬停时显示拖动光标(↔)

### 4.1 菜单结构

```
文件(F)    帮助(H)
```

### 4.3 "帮助"菜单(可选)

```
  ├─ 使用说明(H)...

```

### 4.4 菜单快捷键
- **导入图片**:Ctrl+O
- **覆盖原图导出**:Ctrl+S

- **退出**:Alt+F4

## 5. 左侧操作区设计

### 5.1 区域功能
- 显示所有导入的图片
- 每张图片显示为一个独立的处理单元
- 支持滚动查看所有图片

### 5.2 处理单元布局
每个处理单元包含:
```
┌─────────────────────────────────────┐
│ 文件名: icon.png (512x512)   [关闭]  │ ← 图片信息栏 + 关闭图片按钮
├─────────────────────────────────────┤
│                                     │
│         [图片预览+切割线]           │ ← 图片操作区(第一行)
│                                     │
├─────────────────────────────────────┤
│ 上:50  下:50  左:50  右:50          │ ← 参数控制区(第二行)
│ 缩放:100%  [复制上图参数]          │
└─────────────────────────────────────┘
```

### 5.3 图片信息栏
- **内容**:文件名和原始尺寸
- **示例**:"icon.png (512x512)"
- **样式**:浅色背景,小号字体
- **高度**:约25-30像素
- **关闭图片按钮**:
  - **功能**: 关闭当前图片处理单元,并从列表中移除
  - **样式**: 按钮样式,例如使用一个小号的"X"图标或文本"关闭"
  - **位置**: 靠右对齐,与文件名和尺寸信息在同一行
  - **交互**: 点击时移除对应的图片处理单元



### 5.4 图片操作区
- **功能**:显示图片预览和四条可拖动的切割线
- **尺寸**:
  - 宽度:占满处理单元宽度(留适当边距)
  - 高度:根据图片宽高比自动调整,或固定高度(例如:200-300像素)
- **图片缩放**:图片自动缩放以适应操作区,保持宽高比

### 5.5 参数控制区
- **布局**:水平排列输入框和按钮
- **输入框**:
  - 上、下、左、右切割参数(4个)
  - 缩放系数(1个)
- **按钮**:"复制上图参数"按钮
- **高度**:约40-50像素

### 5.6 处理单元间距
- 处理单元之间有明显的分隔线或间距(例如:10-20像素)
- 使用不同的背景色区分不同的处理单元(可选)

### 5.7 滚动条
- 当图片数量较多时,显示垂直滚动条
- 滚动条样式:系统默认或自定义样式

### 5.8 空状态提示
- **场景**:左侧操作区没有任何图片
- **显示**:
  ```
  ┌─────────────────────────────┐
  │                             │
  │    拖放PNG图片到此处        │
  │    或点击"文件 → 导入图片"  │
  │                             │
  │    [图标:拖放提示]          │
  │                             │
  └─────────────────────────────┘
  ```

## 6. 右侧预览区设计

### 6.1 区域功能
- 实时预览当前选中图片的切割效果
- 显示切割后拼接的结果

### 6.2 预览区布局
```
┌─────────────────────────────────┐
│ 预览: icon.png                  │ ← 预览信息栏
│ 原始: 512x512                   │
│ 切割后: 200x200                 │
│ 缩放: 100% → 最终: 200x200      │
├─────────────────────────────────┤
│                                 │
│                                 │
│         [预览图片]              │ ← 预览图片区
│                                 │
│                                 │
└─────────────────────────────────┘
```

### 6.3 预览信息栏
- **位置**:预览区顶部
- **内容**:
  - 当前预览的图片名称
  - 原始尺寸
  - 切割后尺寸
  - 缩放系数和最终尺寸
- **高度**:约80-100像素
- **样式**:浅色背景,清晰的文字

### 6.4 预览图片区
- **功能**:显示切割后拼接的图片
- **背景**:
  - 透明图片:棋盘格背景
  - 不透明图片:纯色背景(浅灰或白色)
- **图片居中**:预览图片在区域中居中显示
- **自动缩放**:图片自动缩放以适应预览区,保持宽高比

### 6.5 预览工具栏(可选)
- **位置**:预览区底部或顶部
- **按钮**:
  - 上一张
  - 下一张
  - 适应窗口
  - 原始尺寸

### 6.6 空状态提示
- **场景**:没有图片可预览
- **显示**:
  ```
  ┌─────────────────────────────┐
  │                             │
  │      暂无预览内容           │
  │      请先导入图片           │
  │                             │
  └─────────────────────────────┘
  ```

## 7. 底部导出按钮区设计

### 7.1 区域布局
```
┌─────────────────────────────────────┐
│  [ 覆盖原图 ]   [ 导出(添加后缀) ]  │
└─────────────────────────────────────┘
```

### 7.2 按钮设计
- **数量**:2个按钮
- **排列**:水平居中排列
- **间距**:按钮之间有适当间距(例如:20像素)
- **尺寸**:
  - 宽度:120-150像素
  - 高度:40-50像素
- **样式**:
  - "覆盖原图":警告色(橙色或红色)
  - "导出(添加后缀)":主色调(蓝色或绿色)

### 7.3 按钮状态
- **启用**:左侧操作区有图片时
- **禁用**:左侧操作区没有图片时(灰色,不可点击)

## 8. 响应式布局

### 8.1 窗口缩放
- 用户调整窗口大小时,界面应自动调整布局
- 保持各区域的比例和可用性

### 8.2 最小尺寸限制
- 窗口宽度<800像素时,限制继续缩小
- 窗口高度<600像素时,限制继续缩小
- 确保所有功能区域仍然可用

### 8.3 区域自适应
- **左侧操作区**:
  - 宽度减小时,图片预览相应缩小
  - 参数控制区可能换行显示
- **右侧预览区**:
  - 宽度减小时,预览图片相应缩小
  - 保持图片居中和宽高比

### 8.4 高DPI支持
- 支持高分辨率显示器(例如:4K显示器)
- 界面元素自动缩放,保持清晰度
- 文字和图标不应模糊

## 9. 视觉设计

### 9.1 色彩方案
- **主色调**:灰色(专业、可靠)
- **警告色**:橙色或红色(覆盖原图按钮)
- **背景色**:浅灰色(干净、简洁)
- **文字色**:深灰色或黑色(清晰易读)
整体为深色风格,暂不支持切换主题

### 9.2 字体
- **主字体**:系统默认字体或微软雅黑
- **字号**:
  - 菜单:12-14像素
  - 按钮:14-16像素
  - 标签:12像素
  - 输入框:12-14像素

### 9.3 图标
- 使用清晰的图标增强可识别性
- 示例:
  - 导入图片:文件夹图标
  - 导出:保存图标
  - 复制参数:复制图标

### 9.4 间距与对齐
- 使用一致的间距(例如:8像素、16像素、24像素)
- 元素对齐:左对齐、右对齐或居中,保持一致性

## 10. 交互反馈

### 10.1 鼠标悬停
- 按钮:鼠标悬停时高亮或改变颜色
- 切割线手柄:鼠标悬停时高亮
- 菜单项:鼠标悬停时高亮背景

### 10.2 点击反馈
- 按钮:点击时有按下效果(颜色变化或阴影)
- 输入框:点击时显示光标和边框高亮

### 10.3 拖动反馈
- 切割线:拖动时实时更新位置
- 分隔条:拖动时显示拖动光标和实时调整区域宽度

### 10.4 加载状态
- 导入图片时:显示加载进度或旋转图标
- 导出图片时:显示进度对话框

## 11. 无障碍设计(可选)

### 11.1 键盘导航
- 支持Tab键在控件之间切换焦点
- 支持Enter键激活按钮
- 支持方向键调整数值输入框

### 11.2 快捷键
- 提供常用操作的快捷键(见4.4节)
- 快捷键在菜单中显示

### 11.3 对比度
- 确保文字和背景有足够的对比度
- 符合WCAG 2.0 AA级标准(可选)

## 12. 边界情况

### 12.1 超宽或超窄窗口
- **场景**:用户将窗口拉得非常宽或非常窄
- **处理**:
  - 超宽:左右区域按比例扩展,但保持合理的最大宽度
  - 超窄:限制最小宽度,避免界面元素重叠或不可用

### 12.2 超高或超矮窗口
- **场景**:用户将窗口拉得非常高或非常矮
- **处理**:
  - 超高:左侧操作区和右侧预览区扩展,充分利用空间
  - 超矮:限制最小高度,避免界面元素重叠或不可用

### 12.3 多显示器
- **场景**:用户使用多个显示器
- **处理**:
  - 窗口可以在不同显示器之间移动
  - 记住窗口在哪个显示器上(可选)

### 12.4 高DPI和低DPI混合
- **场景**:用户使用不同DPI的多个显示器
- **处理**:
  - 窗口在不同显示器之间移动时,自动调整缩放
  - 保持界面清晰度

- 允许用户自定义左右区域的宽度比例
