# 需求描述
制作一个rust gui 应用
最后想打包成可一键启动的exe
目前只一个目标平台 win(后期再拓展mac,其他明确不持支)
整体架构简单些,避免过多依赖
将 图片 按照 用户 在界面上 拖放设置的 切割线 (上下左右四条) 然后将 四个角拼接起来 生成新的图片
菜单栏 文件 导入图片 打开文件选择器,支持多选 只支持 png(后续再拓展其他格式)
左侧用户裁剪操作区 右侧预览区 底部导出按钮区
左侧操作区 支持拖放图片进入 可支持多图拖入 
多图竖向排列 每个图的处理操作区再分两行 第一行 图片操作区 用户操作四条切割线 线上中间有拖放手柄 第二行 四个输入参数一组 控制 上下左右四条切割线向内移动多少(跟随切割线拖动实时更新) 即 拖放手柄直观快捷操作 参数精确调控.一个等比缩放系数 百分比 控制 图片裁剪后再缩放多少(可缩小可放大,默认100%,即不缩放) 一个 复制上图参数 按钮 用来快捷 复制上图裁剪参数(第一个图此按钮失活)
右侧预览区 实时预览切图后效果(因为有时图片会有纹理或渐变,直接切效果不好,故需要实时预览)
最下方导出按钮区,两个按钮 一个 覆盖原图 一个 加 后缀"_cut"导出
# 需求原因
制作unity 游戏 ui 时 会采用 切九宫的方式 使用 ui图片素材(用小图扩展为大图使用,节约素材体积),但 美术给的图有时是大图,故给程序员制作个便捷应用.
