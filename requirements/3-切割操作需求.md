# 切割操作需求

## 1. 需求概述

本文档描述用户如何在左侧操作区对图片进行九宫格切割操作,包括可视化切割线拖动和精确参数输入两种方式。

## 2. 九宫格切割原理

### 2.1 切割概念说明
- **九宫格切图**:将图片分为9个区域(4个角+4条边+1个中心)
- **本应用目标**:提取四个角并拼接成新图片
- **切割线**:定义四个角的边界
  - 上切割线:定义上边角的下边界
  - 下切割线:定义下边角的上边界
  - 左切割线:定义左边角的右边界
  - 右切割线:定义右边角的左边界

### 2.2 切割示意图
```
原始图片 (形成井字):
┌────┬───────┬────┐
│左上│  上   │右上│ ← 上切割线
├────┼───────┼────┤
│ 左 │  中   │ 右 │
├────┼───────┼────┤
│左下│  下   │右下│ ← 下切割线
└────┴───────┴────┘
  ↑             ↑
左切割线    右切割线

切割后拼接 (提取四角):
┌────┬────┐
│左上│右上│
├────┼────┤
│左下│右下│
└────┴────┘
```

## 3. 操作区布局

### 3.1 单个图片处理单元结构
每张图片在左侧操作区占据一个处理单元,包含两行:

**第一行:图片操作区**
- 显示图片预览
- 显示四条可拖动的切割线
- 每条切割线中间有拖动手柄

**第二行:参数控制区**
- 四个数值输入框(上、下、左、右切割参数)
- 一个缩放系数输入框
- 一个"复制上图参数"按钮

### 3.2 多图排列
- 多张图片在左侧操作区**竖向排列**
- 每个处理单元之间有明显的分隔线或间距
- 支持滚动查看所有图片

## 4. 可视化切割线操作

### 4.1 切割线显示

#### 4.1.1 切割线样式
- **颜色**:醒目的颜色(例如:红色或黄色)
- **线宽**:2-3像素,清晰可见
- **样式**:实线或虚线
- **层级**:显示在图片上方

#### 4.1.2 四条切割线
1. **上切割线**:水平线,从左到右
2. **下切割线**:水平线,从左到右
3. **左切割线**:垂直线,从上到下
4. **右切割线**:垂直线,从上到下

#### 4.1.3 切割线初始位置
- **默认位置**:距离图片边缘一定比例
  - 示例:上切割线距离顶部10%
  - 示例:左切割线距离左边10%
- **可配置**:可以在设置中调整默认位置

### 4.2 拖动手柄

#### 4.2.1 手柄位置
- 每条切割线的**中间位置**显示一个拖动手柄
- 示例:上切割线的手柄在线的水平中心位置

#### 4.2.2 手柄样式
- **形状**:圆形、方形或双向箭头
- **大小**:足够大以便于点击拖动(建议直径/边长≥20像素)
- **颜色**:与切割线颜色一致或对比色
- **鼠标悬停**:鼠标悬停时高亮显示或改变颜色

#### 4.2.3 鼠标光标
- 鼠标悬停在手柄上时,光标应变为对应的拖动光标
  - 上/下切割线手柄:上下双向箭头光标(↕)
  - 左/右切割线手柄:左右双向箭头光标(↔)

### 4.3 拖动操作

#### 4.3.1 拖动方向限制
- **上切割线**:只能上下拖动
- **下切割线**:只能上下拖动
- **左切割线**:只能左右拖动
- **右切割线**:只能左右拖动

#### 4.3.2 拖动范围限制
- **上切割线**:
  - 最小位置:图片顶部(y=0)
  - 最大位置:下切割线位置(不能超过下切割线)
  
- **下切割线**:
  - 最小位置:上切割线位置(不能超过上切割线)
  - 最大位置:图片底部(y=图片高度)
  
- **左切割线**:
  - 最小位置:图片左边(x=0)
  - 最大位置:右切割线位置(不能超过右切割线)
  
- **右切割线**:
  - 最小位置:左切割线位置(不能超过左切割线)
  - 最大位置:图片右边(x=图片宽度)

#### 4.3.3 拖动反馈
- **实时更新**:拖动时切割线位置实时更新
- **参数同步**:拖动时,对应的参数输入框实时更新
- **预览同步**:拖动时,右侧预览区实时更新切割效果

### 4.4 拖动示例

**示例1:正常拖动**
- 用户拖动上切割线向下移动50像素
- 上切割线位置从y=51更新到y=101
- "上"参数输入框从51更新到101
- 右侧预览区显示新的切割效果

**示例2:边界限制**
- 图片高度为512像素
- 下切割线当前位置为y=400
- 用户尝试拖动上切割线到y=450(超过下切割线)
- 上切割线停止在y=400(与下切割线重合)

## 5. 参数输入控制

### 5.1 参数定义

#### 5.1.1 切割参数(4个)
- **上参数**:上切割线距离图片顶部的像素数
- **下参数**:下切割线距离图片底部的像素数
- **左参数**:左切割线距离图片左边的像素数
- **右参数**:右切割线距离图片右边的像素数

**注意**:参数表示"向内移动多少",不是绝对坐标

#### 5.1.2 参数与切割线位置的关系
假设图片宽度为W,高度为H:
- 上切割线的y坐标 = 上参数
- 下切割线的y坐标 = H - 下参数
- 左切割线的x坐标 = 左参数
- 右切割线的x坐标 = W - 右参数

### 5.2 输入框设计

#### 5.2.1 输入框布局
```
[ 上: 50  ] [ 下: 50  ] [ 左: 50  ] [ 右: 50  ] [ 缩放: 100% ] [复制上图参数]
```

#### 5.2.2 输入框属性
- **类型**:数值输入框
- **单位**:像素(切割参数)、百分比(缩放系数)
- **默认值**:
  - 切割参数:0或根据图片尺寸计算的默认值
  - 缩放系数:100%

#### 5.2.3 输入验证
- **有效范围**:
  - 切割参数:0到图片尺寸的一半
  - 示例:512x512图片,上参数范围为0-256
  - 缩放系数:1%-1000%(可根据实际需求调整)

- **非法输入处理**:
  - 负数:自动修正为0
  - 超出范围:自动修正为最大/最小值
  - 非数字:显示错误提示,恢复为上一个有效值

### 5.3 参数与切割线的双向同步

#### 5.3.1 拖动切割线 → 更新参数
- 用户拖动切割线
- 实时计算新的参数值
- 更新对应的输入框数值

#### 5.3.2 输入参数 → 更新切割线
- 用户在输入框中输入新的参数值
- 实时计算新的切割线位置
- 更新切割线显示
- 更新预览区

### 5.4 缩放系数

#### 5.4.1 缩放系数定义
- **作用**:控制切割后拼接图片的缩放比例
- **默认值**:100%(不缩放)
- **范围**:1%-1000%
  - <100%:缩小
  - =100%:不变
  - >100%:放大

#### 5.4.2 缩放示例
- **示例1**:缩放系数50%
  - 原始切割后拼接图片:200x200像素
  - 缩放后:100x100像素

- **示例2**:缩放系数200%
  - 原始切割后拼接图片:200x200像素
  - 缩放后:400x400像素

#### 5.4.3 缩放质量
- 缩小:使用高质量的降采样算法(例如:Lanczos)
- 放大:使用双线性或双三次插值

## 6. 复制上图参数功能

### 6.1 功能说明
- **目的**:快速复制上一张图片的切割参数到当前图片
- **适用场景**:批量处理相似尺寸的图片时,避免重复设置

### 6.2 按钮状态

#### 6.2.1 第一张图片
- **状态**:按钮禁用(灰色)
- **原因**:没有上一张图片可以复制

#### 6.2.2 第二张及之后的图片
- **状态**:按钮启用(可点击)
- **功能**:点击后复制上一张图片的参数

### 6.3 复制的参数
点击"复制上图参数"按钮后,复制以下参数:
- 上切割参数
- 下切割参数
- 左切割参数
- 右切割参数
- 缩放系数

### 6.4 复制行为

#### 6.4.1 绝对像素值复制
- **方式**:直接复制像素值
- **适用**:图片尺寸相同的情况
- **示例**:
  - 第一张图片:512x512,上参数=50
  - 第二张图片:512x512,复制后上参数=50

#### 6.4.2 不同尺寸图片的处理
- **场景**:上一张图片和当前图片尺寸不同
- **处理方式1(推荐)**:按比例缩放参数
  - 示例:
    - 第一张图片:512x512,上参数=51(10%)
    - 第二张图片:1024x1024,复制后上参数=102(10%)

- **处理方式2**:直接复制像素值,超出范围则限制
  - 示例:
    - 第一张图片:1024x1024,上参数=500
    - 第二张图片:512x512,复制后上参数=256(限制为最大值)

### 6.5 复制后的反馈
- 切割线位置立即更新
- 参数输入框立即更新
- 预览区立即更新
- 可选:显示提示"已复制上图参数"

## 7. 边界情况

### 7.1 切割线重合
- **场景**:用户将上切割线拖动到与下切割线重合的位置
- **结果**:四个角的高度为0,拼接后图片高度为0
- **处理**:允许这种情况,但在预览区显示警告"切割区域过小"

### 7.2 切割参数为0(退化为等比缩放)
- **场景**:所有切割参数都为0(上=0、下=0、左=0、右=0)
- **功能退化**:此时不进行切割,功能退化为**等比缩放图片**
- **处理逻辑**:
  - 不提取四个角
  - 直接对原始图片应用缩放系数
  - 导出缩放后的完整图片
- **使用场景**:
  - 用户只需要缩放图片,不需要切割
  - 示例:将512x512的图片缩放为256x256(缩放系数50%)
  - 示例:将1024x1024的图片缩放为2048x2048(缩放系数200%)
- **预览显示**:预览区显示缩放后的完整图片
- **这是合法的使用方式**:不应显示警告或错误提示

### 7.3 切割参数过大
- **场景**:切割参数超过图片尺寸的一半
- **示例**:512x512图片,上参数=300,下参数=300
- **结果**:上下切割线交叉
- **处理**:自动限制参数,使切割线不交叉

### 7.4 缩放系数极端值
- **场景1**:缩放系数为1%
  - 结果:输出图片非常小
  - 处理:允许,但显示警告"缩放系数过小,输出图片可能不可用"

- **场景2**:缩放系数为1000%
  - 结果:输出图片非常大,可能占用大量内存
  - 处理:允许,但显示警告"缩放系数过大,可能影响性能"

### 7.5 图片尺寸不规则
- **场景**:图片宽高比不是1:1
- **示例**:图片尺寸为800x600
- **处理**:正常处理,切割线独立控制,拼接后保持原始宽高比

## 8. 性能要求

### 8.1 实时响应
- 拖动切割线时,界面应流畅响应(60fps)
- 参数输入时,预览应在100ms内更新

### 8.2 多图处理
- 每张图片的切割操作独立,互不影响
- 修改一张图片的参数不应影响其他图片的性能

## 9. 未来扩展

### 9.1 预设参数
- 保存常用的切割参数组合
- 一键应用预设参数到当前图片

### 9.2 批量应用参数
- 将当前图片的参数应用到所有图片
- 或应用到选中的多张图片

### 9.3 撤销/重做
- 支持撤销切割操作
- 支持重做已撤销的操作

### 9.4 切割线吸附
- 切割线拖动时自动吸附到特定位置(例如:10%、25%、50%)
- 辅助用户快速定位
