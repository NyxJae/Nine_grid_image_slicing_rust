## 需求文档特点

### 1. 面向非专业人士
- 使用通俗易懂的语言
- 避免复杂的技术术语
- 提供大量示例说明

### 2. 详细的边界情况
- 每个文档都包含"边界情况"章节
- 涵盖正常情况和异常情况
- 明确错误处理策略

### 3. 无二义性
- 使用精确的描述和定义
- 提供具体的数值范围和示例
- 避免模糊或可多种解释的表述

### 4. 最多使用伪代码
- 需求文档中不包含具体实现代码
- 仅在必要时使用简洁的伪代码或示意图
- 重点描述"做什么",而非"怎么做"

## 术语表

| 术语 | 定义 |
|------|------|
| 九宫格切图 | 将图片分为9个区域(4个角+4条边+1个中心)的切割方式 |
| 切割线 | 定义九宫格切割边界的线条(上、下、左、右共4条) |
| 切割参数 | 切割线距离图片边缘的像素数(上、下、左、右共4个参数) |
| 缩放系数 | 切割后图片的缩放比例,以百分比表示 |
| 拼接 | 将四个角组合成一张新图片的过程 |
| 覆盖原图 | 用处理后的图片替换原始图片文件 |
| 添加后缀 | 在原始文件名后添加"_cut"后缀,保存为新文件 |
