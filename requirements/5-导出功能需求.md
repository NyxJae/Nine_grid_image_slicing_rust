# 导出功能需求

## 1. 需求概述

本文档描述用户如何导出处理后的图片,包括覆盖原图和添加后缀导出两种方式。

## 2. 导出按钮区布局

### 2.1 位置
- **位置**:应用窗口最下方
- **布局**:水平排列两个按钮,居中显示

### 2.2 按钮设计
```
┌─────────────────────────────────────┐
│  [ 覆盖原图 ]   [ 导出(添加后缀) ]  │
└─────────────────────────────────────┘
```

### 2.3 按钮样式
- **尺寸**:足够大以便于点击(建议宽度≥120像素,高度≥40像素)
- **颜色**:
  - "覆盖原图"按钮:警告色(例如:橙色或红色),提示用户此操作会修改原文件
  - "导出(添加后缀)"按钮:主色调(例如:蓝色或绿色),推荐的安全操作
- **图标**:可选,添加图标增强可识别性

## 3. 导出方式

### 3.1 覆盖原图

#### 3.1.1 功能说明
- **操作**:用户点击"覆盖原图"按钮
- **结果**:处理后的图片直接覆盖原始图片文件
- **文件名**:保持原始文件名不变

#### 3.1.2 操作流程
1. 用户点击"覆盖原图"按钮
2. 显示确认对话框(见3.1.3)
3. 用户确认后,开始导出
4. 逐个处理左侧操作区的所有图片
5. 将处理后的图片覆盖原始文件
6. 显示导出完成提示

#### 3.1.3 确认对话框
由于覆盖原图是不可逆操作,必须显示确认对话框:
- **标题**:"确认覆盖原图"
- **内容**:
  ```
  此操作将覆盖以下 [N] 个原始图片文件,无法撤销!
  
  - icon.png
  - button.png
  - ...
  
  是否继续?
  ```
- **按钮**:
  - "确认覆盖"(警告色)
  - "取消"(默认选中)

#### 3.1.4 覆盖示例
- **原始文件**:`E:\Assets\icon.png` (512x512)
- **处理后**:`E:\Assets\icon.png` (200x200,切割后拼接的图片)
- **结果**:原始512x512的图片被200x200的图片替换

### 3.2 导出(添加后缀)

#### 3.2.1 功能说明
- **操作**:用户点击"导出(添加后缀)"按钮
- **结果**:处理后的图片保存为新文件,原始文件保持不变
- **文件名**:在原始文件名后添加后缀`_cut`

#### 3.2.2 操作流程
1. 用户点击"导出(添加后缀)"按钮
2. 开始导出(无需确认对话框,因为不会覆盖原文件)
3. 逐个处理左侧操作区的所有图片
4. 将处理后的图片保存为新文件
5. 显示导出完成提示

#### 3.2.3 文件命名规则
- **基本规则**:在文件名(不含扩展名)后添加`_cut`,然后加上扩展名
- **示例**:
  - 原始文件:`icon.png` → 导出文件:`icon_cut.png`
  - 原始文件:`button_normal.png` → 导出文件:`button_normal_cut.png`

#### 3.2.4 文件保存位置
- **默认位置**:与原始文件相同的文件夹
- **示例**:
  - 原始文件:`E:\Assets\icon.png`
  - 导出文件:`E:\Assets\icon_cut.png`

#### 3.2.5 文件名冲突处理
- **场景**:导出文件已存在
- **示例**:文件夹中已有`icon_cut.png`
- **处理方式**:
  - **方式1(推荐)**:显示确认对话框,询问是否覆盖
    ```
    文件 icon_cut.png 已存在,是否覆盖?
    [覆盖] [跳过] [全部覆盖] [全部跳过] [取消]
    ```
  - **方式2**:自动添加数字后缀
    - 示例:`icon_cut.png` → `icon_cut_1.png` → `icon_cut_2.png`

## 4. 导出处理逻辑

### 4.1 图片处理流程
对于每张图片,执行以下步骤:
1. **读取原始图片**
2. **判断是否需要切割**:
   - 如果所有切割参数都为0(上=0、下=0、左=0、右=0):
     - 跳过步骤3和4,直接进入步骤5
     - 此时功能退化为**等比缩放**
   - 否则,继续执行步骤3
3. **根据切割参数提取四个角**(仅当切割参数不全为0时):
   - 左上角:从(0, 0)到(左参数, 上参数)
   - 右上角:从(宽度-右参数, 0)到(宽度, 上参数)
   - 左下角:从(0, 高度-下参数)到(左参数, 高度)
   - 右下角:从(宽度-右参数, 高度-下参数)到(宽度, 高度)
4. **拼接四个角**(仅当切割参数不全为0时):
   ```
   ┌────────┬────────┐
   │ 左上角 │ 右上角 │
   ├────────┼────────┤
   │ 左下角 │ 右下角 │
   └────────┴────────┘
   ```
5. **应用缩放系数**:
   - 如果缩放系数≠100%,缩放图片(切割后拼接的图片或原始完整图片)
6. **保存为PNG文件**

### 4.2 图片质量
- **PNG压缩**:使用无损压缩
- **透明通道**:保留原始图片的透明通道(Alpha通道)
- **色彩深度**:保持原始图片的色彩深度(例如:24位RGB或32位RGBA)

### 4.3 批量导出
- **处理顺序**:按照左侧操作区从上到下的顺序处理
- **进度显示**:显示导出进度
  - 示例:"正在导出 3/10..."
  - 进度条显示整体进度

### 4.4 导出速度
- **性能要求**:
  - 单张512x512图片导出时间应<1秒
  - 批量导出10张图片应<10秒
- **优化**:
  - 使用多线程并行处理多张图片(可选)
  - 显示进度条,避免用户认为程序卡死

## 5. 导出反馈

### 5.1 导出进度提示
- **进度对话框**:
  - 标题:"正在导出..."
  - 内容:"正在导出 3/10: icon.png"
  - 进度条:显示整体进度百分比
  - "取消"按钮:允许用户中途取消导出

### 5.2 导出完成提示
- **成功提示**:
  - 标题:"导出完成"
  - 内容:"已成功导出 10 张图片"
  - 可选:显示导出文件的保存位置
  - 可选:"打开文件夹"按钮,打开导出文件所在的文件夹

### 5.3 部分失败提示
- **场景**:部分图片导出成功,部分失败
- **提示**:
  - 标题:"导出完成(部分失败)"
  - 内容:
    ```
    成功导出: 8 张
    失败: 2 张
    
    失败的文件:
    - icon.png (磁盘空间不足)
    - button.png (文件被占用)
    ```

### 5.4 全部失败提示
- **场景**:所有图片导出失败
- **提示**:
  - 标题:"导出失败"
  - 内容:"所有图片导出失败,请检查磁盘空间和文件权限"

## 6. 错误处理

### 6.1 磁盘空间不足
- **场景**:导出时磁盘空间不足
- **处理**:
  - 停止导出
  - 显示错误提示:"磁盘空间不足,无法保存文件"
  - 已导出的文件保留,未导出的文件跳过

### 6.2 文件写入权限不足
- **场景**:目标文件夹没有写入权限
- **示例**:尝试覆盖系统保护的文件
- **处理**:
  - 显示错误提示:"无法写入文件:[文件名],权限不足"
  - 跳过该文件,继续导出其他文件

### 6.3 文件被占用
- **场景**:目标文件正在被其他程序使用
- **示例**:原始文件正在被图片查看器打开
- **处理**:
  - 显示错误提示:"文件被占用,无法覆盖:[文件名]"
  - 跳过该文件,继续导出其他文件

### 6.4 图片处理失败
- **场景**:图片处理过程中出现错误
- **示例**:内存不足,无法处理超大图片
- **处理**:
  - 显示错误提示:"图片处理失败:[文件名],原因:[错误信息]"
  - 跳过该文件,继续导出其他文件

### 6.5 无图片可导出
- **场景**:左侧操作区没有任何图片
- **处理**:
  - 导出按钮禁用(灰色)
  - 或点击后显示提示:"请先导入图片"

## 7. 边界情况

### 7.1 切割参数全为0(等比缩放模式)
- **场景**:所有切割参数为0(上=0、下=0、左=0、右=0)
- **功能说明**:此时功能退化为**等比缩放图片**,不进行切割操作
- **处理**:
  - 直接对原始完整图片应用缩放系数
  - 导出缩放后的完整图片
  - **不显示警告**,这是合法的使用方式
- **示例**:
  - 原始图片:512x512,切割参数全为0,缩放系数50%
  - 导出结果:256x256的完整图片(未切割,仅缩放)

### 7.2 切割区域过小
- **场景**:切割参数过小,四个角尺寸<10像素
- **处理**:
  - 正常导出,但显示警告:"切割区域过小,导出的图片可能不清晰"

### 7.3 缩放系数极端值
- **场景1**:缩放系数为1%
  - 导出极小的图片(可能只有几个像素)
  - 显示警告:"缩放系数过小,导出的图片可能不可用"

- **场景2**:缩放系数为1000%
  - 导出极大的图片,可能占用大量磁盘空间
  - 显示警告:"缩放系数过大,导出的图片可能占用大量磁盘空间"

### 7.4 原始文件已删除
- **场景**:用户导入图片后,删除了原始文件
- **处理**:
  - 如果应用已将图片加载到内存,仍可正常导出
  - 如果需要重新读取原始文件,显示错误:"原始文件不存在:[文件路径]"

### 7.5 文件路径过长
- **场景**:Windows系统路径长度限制(MAX_PATH=260字符)
- **示例**:原始文件路径已接近260字符,添加`_cut`后缀后超出限制
- **处理**:
  - 显示错误提示:"文件路径过长,无法保存"
  - 建议用户缩短文件名或移动文件到更短的路径

## 8. 导出选项(可选功能)

### 8.1 自定义后缀
- 允许用户自定义导出文件的后缀
- 默认为`_cut`,用户可修改为其他后缀(例如:`_9grid`、`_sliced`)

### 8.2 选择导出位置
- 允许用户选择导出文件的保存位置
- 默认为原始文件所在文件夹,用户可选择其他文件夹

### 8.3 导出格式选择
- 当前版本仅支持PNG格式
- 未来可扩展支持其他格式(JPEG、WebP等)

### 8.4 批量导出设置
- 允许用户选择导出部分图片,而非全部
- 示例:用户勾选要导出的图片,只导出选中的图片

## 9. 性能优化

### 9.1 并行处理
- 使用多线程并行处理多张图片
- 充分利用多核CPU,提高导出速度

### 9.2 内存管理
- 逐个处理图片,避免同时加载所有图片到内存
- 处理完一张图片后,释放其占用的内存

### 9.3 进度反馈
- 实时更新进度条,让用户了解导出进度
- 避免用户认为程序卡死或无响应

## 10. 未来扩展

### 10.1 导出预设
- 保存常用的导出设置(后缀、保存位置等)
- 一键应用预设进行导出

### 10.2 批量重命名
- 导出时支持批量重命名
- 示例:按照序号重命名(icon_1.png、icon_2.png等)

### 10.3 导出日志
- 记录导出历史和结果
- 方便用户查看之前的导出操作

### 10.4 导出到压缩包
- 将所有导出的图片打包为ZIP文件
- 方便用户分享或归档
