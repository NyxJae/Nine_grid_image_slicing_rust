# 图片导入需求

## 1. 需求概述

本文档描述用户如何将图片导入到应用中进行处理,包括菜单导入和拖放导入两种方式。

## 2. 导入方式

### 2.1 菜单栏导入

#### 2.1.1 菜单结构
- **菜单栏位置**:应用窗口顶部
- **菜单项**:
  ```
  文件(F)
    └─ 导入图片(I)...
  ```

#### 2.1.2 操作流程
1. 用户点击"文件"菜单
2. 点击"导入图片"选项
3. 打开文件选择对话框
4. 用户选择一个或多个PNG文件
5. 点击"打开"按钮
6. 图片加载到左侧操作区

#### 2.1.3 文件选择对话框要求
- **支持多选**:用户可以一次选择多个文件
  - 示例:用户按住Ctrl键可选择多个不连续的文件
  - 示例:用户按住Shift键可选择连续的多个文件
  
- **文件过滤**:
  - 只显示PNG格式的图片文件
  - 文件扩展名过滤:`.png`(不区分大小写)
  - 对话框标题:"选择PNG图片"

- **默认路径**:
  - 首次打开:系统图片文件夹或上次打开的文件夹
  - 后续打开:记住上次选择文件的文件夹路径

### 2.2 拖放导入

#### 2.2.1 拖放区域
- **主拖放区**:左侧操作区整个区域
- **视觉反馈**:
  - 当用户拖动文件到窗口上方时,左侧操作区应显示视觉提示
  - 示例:边框高亮、背景色变化、显示"拖放图片到此处"文字

#### 2.2.2 操作流程
1. 用户从文件管理器(资源管理器)选择一个或多个PNG文件
2. 拖动文件到应用窗口的左侧操作区
3. 释放鼠标(Drop)
4. 图片加载到左侧操作区

#### 2.2.3 拖放支持
- **支持多文件拖放**:
  - 用户可以一次拖放多个PNG文件
  - 示例:用户选择5个PNG文件,一起拖放到应用中

- **文件夹拖放**:
  - 当前版本不支持拖放文件夹
  - 如果用户拖放了文件夹,应显示提示:"请直接拖放PNG图片文件"

## 3. 文件格式验证

### 3.1 支持的格式
- **当前版本**:仅支持PNG格式
  - 文件扩展名:`.png`(不区分大小写)
  - 文件内容:必须是有效的PNG图片文件

### 3.2 格式验证规则

#### 3.2.1 扩展名验证
- 检查文件扩展名是否为`.png`
- 不区分大小写(`.PNG`、`.Png`都应接受)

#### 3.2.2 文件内容验证
- 验证文件是否为有效的PNG图片
- 检查PNG文件头(magic number)
- 确保图片可以被正常解码

### 3.3 错误处理

#### 3.3.1 不支持的文件格式
- **场景**:用户选择或拖放了非PNG文件
- **示例**:用户拖放了`image.jpg`文件
- **处理**:
  - 显示错误提示对话框
  - 提示内容:"不支持的文件格式,请选择PNG图片"
  - 列出不支持的文件名
  - 其他有效的PNG文件仍然正常加载

#### 3.3.2 文件损坏
- **场景**:PNG文件损坏或不完整
- **示例**:文件扩展名是`.png`,但内容不是有效的PNG数据
- **处理**:
  - 显示错误提示对话框
  - 提示内容:"图片文件损坏,无法打开:[文件名]"
  - 其他有效的PNG文件仍然正常加载

#### 3.3.3 文件过大
- **场景**:图片尺寸超过支持的最大尺寸
- **示例**:用户导入了一张8192x8192像素的PNG图片
- **处理**:
  - 显示警告提示对话框
  - 提示内容:"图片尺寸过大([宽]x[高]),可能影响性能"
  - 询问用户是否继续加载
  - 用户可选择"继续"或"取消"

#### 3.3.4 文件读取失败
- **场景**:文件被其他程序占用或无读取权限
- **示例**:文件正在被Photoshop编辑并锁定
- **处理**:
  - 显示错误提示对话框
  - 提示内容:"无法读取文件:[文件名],文件可能被其他程序占用"

## 4. 图片加载

### 4.1 加载顺序
- **多文件加载**:按照用户选择或拖放的顺序加载
- **显示顺序**:在左侧操作区从上到下竖向排列

### 4.2 加载反馈
- **加载进度**:
  - 如果图片较大或数量较多,应显示加载进度
  - 示例:"正在加载图片 3/10..."
  
- **加载完成**:
  - 所有图片加载完成后,显示在左侧操作区
  - 每张图片显示为独立的处理单元

### 4.3 重复导入处理
- **场景**:用户导入了已经在操作区中的图片
- **处理方式**:
  - 方案1(推荐):允许重复导入,作为新的处理单元添加
  - 方案2:检测重复,询问用户是否替换或添加新副本
  
- **示例**:
  - 用户已导入`icon.png`
  - 用户再次导入`icon.png`
  - 应用将其作为第二个独立的处理单元添加到列表中

## 5. 导入后的状态

### 5.1 初始状态
每张导入的图片应具有以下初始状态:
- **切割线位置**:默认位置(例如:距离边缘10%的位置)
- **切割参数**:上下左右均为默认值(例如:0像素)
- **缩放系数**:100%(不缩放)
- **预览**:右侧预览区显示第一张图片的切割效果

### 5.2 图片信息显示
每张图片应显示以下信息:
- 文件名(不含路径)
- 原始尺寸(宽x高,单位:像素)
- 示例:"icon.png (512x512)"

## 6. 边界情况

### 6.1 空文件选择
- **场景**:用户打开文件选择对话框后,没有选择任何文件,直接点击"取消"
- **处理**:不做任何操作,保持当前状态

### 6.2 混合文件类型
- **场景**:用户同时选择了PNG和非PNG文件
- **示例**:用户选择了`a.png`、`b.jpg`、`c.png`
- **处理**:
  - 只加载PNG文件(`a.png`和`c.png`)
  - 显示提示:"已忽略2个不支持的文件"

### 6.3 大量文件导入
- **场景**:用户一次导入大量图片(例如:50张)
- **处理**:
  - 正常加载所有图片
  - 如果加载时间较长,显示进度条
  - 左侧操作区支持滚动查看所有图片

### 6.4 图片尺寸极小
- **场景**:用户导入的图片尺寸非常小
- **示例**:图片尺寸为16x16像素
- **处理**:
  - 正常加载
  - 显示警告:"图片尺寸过小([宽]x[高]),切割效果可能不理想"

### 6.5 透明PNG图片
- **场景**:PNG图片包含透明通道(Alpha通道)
- **处理**:
  - 正常加载和处理
  - 预览时使用棋盘格背景显示透明区域
  - 导出时保留透明通道

## 7. 未来扩展

### 7.1 支持更多格式
- JPEG格式
- WebP格式
- BMP格式

### 7.2 批量导入优化
- 支持拖放文件夹,自动扫描其中的PNG文件
- 支持通配符选择(例如:`*.png`)

### 7.3 导入历史
- 记录最近导入的文件路径
- 提供"最近使用"快捷菜单
