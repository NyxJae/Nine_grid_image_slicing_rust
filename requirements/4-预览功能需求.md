# 预览功能需求

## 1. 需求概述

本文档描述右侧预览区的功能需求,用户可以实时查看切割后的效果,确保切割参数符合预期。

## 2. 预览区布局

### 2.1 位置与尺寸
- **位置**:应用窗口右侧
- **宽度**:占据窗口右侧约40%-50%的空间
- **高度**:与左侧操作区对齐,占据菜单栏下方到导出按钮区上方的空间

### 2.2 预览区标题
- 显示当前预览的图片信息
- 示例:"预览: icon.png (切割后: 200x200)"

## 3. 预览内容

### 3.1 预览对象
- **默认预览**:左侧操作区的第一张图片
- **切换预览**:
  - 方式1:用户点击左侧操作区的某张图片,预览区切换到该图片
  - 方式2:用户滚动左侧操作区时,预览区自动切换到当前可见的图片
  - 方式3:提供上一张/下一张按钮切换预览

### 3.2 预览图片内容
预览区显示**切割后拼接的结果**,即四个角拼接成的新图片:
```
┌────────┬────────┐
│ 左上角 │ 右上角 │
├────────┼────────┤
│ 左下角 │ 右下角 │
└────────┴────────┘
```

### 3.3 预览图片尺寸
- **原始尺寸**:显示实际切割后的图片尺寸
- **缩放显示**:如果图片过大,自动缩放以适应预览区
- **缩放比例显示**:显示当前预览的缩放比例
  - 示例:"100% (原始尺寸)"
  - 示例:"50% (适应窗口)"

## 4. 实时更新

### 4.1 更新触发条件
预览区应在以下情况下实时更新:
1. 用户拖动切割线
2. 用户修改切割参数(上、下、左、右)
3. 用户修改缩放系数
4. 用户点击"复制上图参数"按钮

### 4.2 更新性能要求
- **延迟**:更新延迟应<100ms(对于常规大小的图片)
- **流畅性**:拖动切割线时,预览应流畅更新,不应出现卡顿
- **优化策略**:
  - 对于大图片,可以使用降采样预览
  - 拖动过程中可以使用低质量预览,拖动结束后使用高质量预览

### 4.3 更新示例

**示例1:拖动切割线**
1. 用户拖动上切割线向下移动
2. 预览区立即显示新的切割效果
3. 左上角和右上角的高度增加

**示例2:修改缩放系数**
1. 用户将缩放系数从100%改为50%
2. 预览区立即显示缩小后的图片
3. 预览图片尺寸减半

## 5. 预览显示细节

### 5.1 背景处理
- **透明图片**:使用棋盘格背景显示透明区域
  - 棋盘格颜色:浅灰和白色交替
  - 棋盘格大小:8x8或16x16像素

- **不透明图片**:使用纯色背景(例如:浅灰色或白色)

### 5.2 图片居中显示
- 预览图片应在预览区中居中显示
- 四周留有适当的边距

### 5.3 缩放控制
- **自动适应**:默认情况下,图片自动缩放以适应预览区
- **手动缩放**:提供缩放控件(可选功能)
  - 缩放按钮:放大(+)、缩小(-)、适应窗口(100%)
  - 鼠标滚轮:Ctrl+滚轮缩放预览图片

### 5.4 分割线不显示
预览区域不显示分割线

## 6. 预览信息显示

### 6.1 图片信息
在预览区显示以下信息:
- **原始图片名称**:例如"icon.png"
- **原始图片尺寸**:例如"512x512"
- **切割后尺寸**:例如"200x200"
- **缩放系数**:例如"100%"
- **最终输出尺寸**:例如"200x200"(应用缩放后)

### 6.2 信息布局示例
```
┌─────────────────────────────────┐
│ 预览: icon.png                  │
│ 原始: 512x512                   │
│ 切割后: 200x200                 │
│ 缩放: 100% → 最终: 200x200      │
├─────────────────────────────────┤
│                                 │
│         [预览图片]              │
│                                 │
└─────────────────────────────────┘
```

## 7. 预览质量

### 7.1 图片渲染质量
- **高质量渲染**:使用高质量的图片缩放算法
- **抗锯齿**:启用抗锯齿以获得平滑的边缘

### 7.2 性能与质量平衡
- **拖动时**:可以使用较低质量的快速渲染
- **静止时**:使用高质量渲染
- **大图片**:自动降低预览分辨率以保持性能

## 8. 边界情况

### 8.1 切割参数全为0(等比缩放模式)
- **场景**:所有切割参数为0(上=0、下=0、左=0、右=0)
- **功能说明**:功能退化为**等比缩放图片**
- **预览显示**:显示缩放后的完整原始图片(不进行切割)
- **提示**:不显示警告,这是合法的使用方式
- **示例**:
  - 原始图片512x512,切割参数全为0,缩放系数50%
  - 预览显示:256x256的完整图片

### 8.2 切割区域过小
- **场景**:切割参数过小,四个角尺寸<10像素
- **预览显示**:正常显示,但可能看不清细节
- **提示**:显示警告"切割区域过小,输出图片可能不清晰"

### 8.3 缩放系数极端值
- **场景1**:缩放系数为1%
  - 预览显示:极小的图片,可能只有几个像素
  - 提示:显示警告"缩放系数过小,预览可能不可见"

- **场景2**:缩放系数为1000%
  - 预览显示:极大的图片,可能超出预览区
  - 处理:自动缩放以适应预览区
  - 提示:显示警告"缩放系数过大,预览已自动缩小显示"

### 8.4 图片纹理或渐变
- **场景**:图片包含纹理或渐变,直接切割可能导致拼接处不连续
- **预览作用**:用户可以通过预览发现问题,调整切割参数
- **示例**:
  - 原始图片有从上到下的渐变
  - 切割后,左上角和左下角拼接处可能出现明显的色差
  - 用户通过预览发现问题,调整切割线位置

### 8.5 透明度处理
- **场景**:PNG图片包含半透明区域
- **预览显示**:使用棋盘格背景正确显示透明度
- **拼接处理**:确保拼接时保留透明通道

### 8.6 多图切换
- **场景**:用户快速切换预览的图片
- **处理**:
  - 取消正在进行的预览渲染
  - 立即开始渲染新选中的图片
  - 避免多个预览任务堆积

## 9. 用户交互

### 9.1 选择预览图片
- **点击选择**:用户点击左侧操作区的某张图片,预览区切换到该图片
- **视觉反馈**:当前预览的图片在左侧操作区应有高亮边框或背景色

### 9.2 预览区工具栏(可选)
提供以下工具按钮:
- **上一张**:切换到上一张图片的预览
- **下一张**:切换到下一张图片的预览
- **适应窗口**:自动缩放预览图片以适应预览区
- **原始尺寸**:以100%尺寸显示预览图片
- **刷新**:手动刷新预览(通常不需要,因为是实时更新)

### 9.3 预览区右键菜单(可选)
- **复制预览图片**:将预览图片复制到剪贴板
- **保存预览图片**:将预览图片保存为文件(快速导出)

## 10. 性能优化

### 10.1 延迟渲染
- 用户快速拖动切割线时,不必每次都立即渲染
- 使用防抖(debounce)技术,拖动停止后再渲染高质量预览

### 10.2 缓存机制
- 缓存已渲染的预览图片
- 当用户切换回之前预览过的图片时,直接使用缓存

### 10.3 异步渲染
- 预览渲染在后台线程进行,不阻塞UI线程
- 渲染完成后更新预览区显示

### 10.4 降采样预览
- 对于超大图片(例如:4096x4096),使用降采样版本进行预览
- 在预览区显示"预览为降采样版本,实际导出为原始质量"

## 11. 错误处理

### 11.1 渲染失败
- **场景**:由于内存不足或其他原因,预览渲染失败
- **处理**:
  - 显示错误提示:"预览渲染失败,请尝试减小图片尺寸或缩放系数"
  - 预览区显示占位符或错误图标

### 11.2 参数无效
- **场景**:切割参数导致无效的切割区域
- **处理**:
  - 显示警告提示:"切割参数无效,请检查参数设置"
  - 预览区显示上一次有效的预览或空白

## 12. 未来扩展

### 12.1 对比预览
- 并排显示原始图片和切割后图片
- 帮助用户更直观地理解切割效果

### 12.2 网格辅助线
- 在预览图片上显示网格辅助线
- 帮助用户对齐和调整切割位置

### 12.3 预览历史
- 记录预览历史,用户可以查看之前的预览效果
- 支持撤销/重做时同步预览

### 12.4 导出预览
- 直接从预览区导出当前预览的图片
- 无需点击底部导出按钮
